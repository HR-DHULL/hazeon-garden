# AI Automations

Everything I know about building AI-powered automation workflows.

## Tools I Use

- **Claude Code** — AI pair programming, content generation, vault management
- **n8n** — Open-source workflow automation (self-hosted)
- **Make.com** — Visual automation for non-technical workflows
- **Python + FastAPI** — Custom AI backends
- **Gemini API** — Content generation at scale

## Automation Philosophies

1. **Automate the repeatable, not the creative** — Use AI to handle data processing, formatting, and distribution. Keep the creative thinking human.
2. **Build once, run forever** — Every automation should save more time than it took to build within the first week.
3. **Chain, don't replace** — The best automations chain multiple AI tools together rather than trying to find one tool that does everything.

## My Automation Stack

```
Input (idea/data) 
  → Claude/Gemini (process/generate)
  → Python (transform/format)
  → n8n (distribute/schedule)
  → Platforms (publish)
```
