# Content Creation

Building a personal brand across YouTube, Instagram, X, and LinkedIn.

## The Repurposing Framework

Every piece of long-form content becomes 5-10 pieces:

```
1 YouTube Video (10 min)
  → 3 Instagram Reels (key moments)
  → 2 Instagram Carousels (frameworks/lists)
  → 1 X Thread (key insights)
  → 1 LinkedIn Post (professional angle)
  → 1 Blog Post (SEO version)
  → 5+ Social Quotes (shareable snippets)
```

## Platform Strategy

| Platform | Content Type | Frequency | Goal |
|---|---|---|---|
| YouTube | Tutorials, demos, BTS | 1/week | Authority + SEO |
| Instagram | Reels, carousels, stories | 5/week | Reach + engagement |
| X | Threads, quick tips | Daily | Network + visibility |
| LinkedIn | Case studies, insights | 3/week | Professional leads |

## Content Pillars

1. **AI Automation tutorials** — how-tos, tool reviews, workflow breakdowns
2. **Building in public** — sharing the journey of building Hazeon
3. **Web development** — coding tutorials, architecture decisions
4. **Productivity** — tools, systems, second brain methodology
